# AGENTS.md — TokenConsumption

Project-level instructions for Codex. This file is committed to the repository,
so everyone who clones it gets the same instructions.

## Commits and pull requests

- Codex-generated commits and pull requests for this repo **must not** include any
  Codex co-author or attribution lines (for example a `Co-Authored-By: Codex ...`
  trailer or a "Generated with Codex" footer).
- Do not rewrite existing commit history or edit existing PRs to remove such lines.

Note: this repo-level instruction is what gets shared through Git. Each contributor's
own `~/.Codex/settings.json` (for example an `attribution` setting) is user-level and
is **not** shared through the repository.
