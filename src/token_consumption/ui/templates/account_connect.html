Connect official Admin API

No password field. No Claude email/password login here — ever. Authentication is a single environment variable holding an Admin API key from the Anthropic Console. This app never asks for your Claude account credentials.

Setup

  1. Requires a Console organization (Console → Settings → Organization). Per Anthropic's docs, "The Admin API is unavailable for individual accounts" — this generally does not apply to personal Pro/Max subscriptions.
  2. Create an Admin API key in the Console (needs Admin/Billing permission on the org).
  3. Set the environment variable before starting Claude Code / this app: 
    setx ANTHROPIC_ADMIN_API_KEY "sk-ant-admin01-..."
    Optional: ANTHROPIC_ORG_ID, ANTHROPIC_WORKSPACE_ID.
  4. Restart the dashboard, then click "Test connection" below.

See docs/ANTHROPIC_API_SETUP.md for full detail and troubleshooting.
