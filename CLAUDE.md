# CLAUDE.md — TokenConsumption

Project-level instructions for Claude Code. This file is committed to the repository,
so everyone who clones it gets the same instructions.

## Commits and pull requests

- Claude-generated commits and pull requests for this repo **must not** include any
  Claude co-author or attribution lines (for example a `Co-Authored-By: Claude ...`
  trailer or a "Generated with Claude Code" footer).
- Do not rewrite existing commit history or edit existing PRs to remove such lines.

Note: this repo-level instruction is what gets shared through Git. Each contributor's
own `~/.claude/settings.json` (for example an `attribution` setting) is user-level and
is **not** shared through the repository.
